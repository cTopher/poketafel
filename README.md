# Pokétafel 🎮✖️

A Pokémon-inspired multiplication tables game for children, built with React, TypeScript, and Vite.

🔗 **[Play it here](https://banaan.dev/poketafel)**

## What is this?

**Pokétafel** (Dutch for "Poké-tables") is a fun, educational game that helps children practise their multiplication tables. Inspired by the world of Pokémon and powered by the [PokéAPI](https://pokeapi.co/), kids can battle wild Pokémon by answering multiplication questions correctly. Answer right and you win the battle — answer wrong and your Pokémon takes a hit!

The goal is to make learning math feel like an adventure rather than a chore.
